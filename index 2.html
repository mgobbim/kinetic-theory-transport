Build the kinetic equation

1
Equations of motion: dx/dt = v, dv/dt = a(x).
2
Liouville: ∂xv + ∂va = 0, so phase-space area is preserved.
3
Collisionless conservation: df/dt = 0 along the particle trajectories.
Chain rule
df/dt = ∂f/∂t + (dx/dt) ∂f/∂x + (dv/dt) ∂f/∂v
Vlasov equation (1D–1V)
∂f/∂t + v ∂f/∂x + a(x) ∂f/∂v = 0
C_BGK[f] = ν (M[n,u,T] − f)
where a(x) = 0
Scope of this demonstration. The simple collisionless cases use exact characteristics; nonlinear-force cases use reversible area-preserving characteristic tracing. BGK uses numerical split-step evolution. This is not a self-consistent plasma or Coulomb/Landau collision calculation.
